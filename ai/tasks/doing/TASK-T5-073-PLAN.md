# TASK-T5-073 Plan

- State: `DONE`
- Objective: refine canonical script, note, and generation authoring cards with a compact shared header/body/status grammar while preserving Revid's media-first Canvas, single mutation owner, geometry, and performance contracts.

## Visual thesis

- Structured graphite authoring cards with quiet violet interaction.
- Header identifies type and title, body previews bounded content, and one restrained local status expression reports lifecycle.
- Image, video, and generated results remain intrinsic media surfaces without permanent card headers.

## Clean-room reference decision

- Adopt only the reference project's high-level separation of type identity, title, content, and status.
- Reimplement through Revid's typed registry, Leafer renderer, shared geometry, tokens, and command model.
- Reject VueFlow components, store/schema patterns, emoji icons, inline actions, selectors, strong purple chrome, and source/SCSS copying.
- No substantial source is copied, so MIT attribution is not required for this implementation unless the final diff changes that fact.

## Delivery sequence

1. Capture the pre-change authoring/media/editor baselines and add pure plus browser RED coverage.
2. Add one pure authoring-card presentation resolver with canonical eligibility, bounded slots, lifecycle, lock, empty, and recipe-safe content.
3. Render the shared shell in Leafer while keeping media/result rendering and port geometry unchanged.
4. Align the selected composer to the shared card slots without adding another editor or mutation path.
5. Reconcile status ownership so canonical authoring cards expose one lifecycle expression.
6. Run focused presentation, geometry, editing, keyboard, responsive, generation, media, visual, and performance regressions from a fresh build.
7. Inspect required viewports and zooms, audit zero mutation, file size, UTF-8, attribution, diff, and sensitive paths.
8. Publish REPORT, close state documents, commit exactly the scoped Task, and push.

## Acceptance invariants

- Only canonical script, note, and generation nodes gain the shared card hierarchy.
- Media/results preserve intrinsic ratio, single DOM media surface, playback, frame tools, comparison, and external labeling.
- CanvasContextPanel remains the only generation action, quota, retry, inputs, preflight, and history owner.
- One selected editable node creates one DOM composer and one existing mutation owner; IME, 500ms commit, blur/Escape flush, autosave, undo/redo, reload, drag, lock, and readonly remain intact.
- Shared world geometry owns card slots, ports, edges, selection, minimap, fit, collision, toolbar, and continuation alignment.
- Visual-only state transitions produce zero document PATCH, history, selection, or viewport persistence mutations.
- Idle authoring cards remain Leafer-rendered and the 200-node/300-connection performance threshold is re-audited after renderer changes.

## Stop rule

- T5-073 closes only after every non-deferred acceptance criterion has current evidence from the final production build.
- Any backend/provider/schema need, second mutation owner, or media framing regression stops the implementation rather than expanding scope.
