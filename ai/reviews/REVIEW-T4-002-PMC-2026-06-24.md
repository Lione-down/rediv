## Required Rework

1. 测试 fixture 只接受 `REVID_TEST_MYSQL_ADMIN_URL`；缺失即明确 BLOCKED，禁止任何 credential fallback。
2. 使用 SQLAlchemy `make_url()`/`URL.set(database=...)` 结构化派生 target URL。
3. CREATE/DROP 前断言目标 database 精确等于 `revid_test_t4_002`；连接后再次查询并确认 database identity。
4. 通过 Alembic `upgrade head` 创建测试 schema，删除手写 `_CREATE_TABLES_SQL` schema ownership。
5. cleanup 失败必须令测试失败或在结果中形成明确阻塞证据，禁止静默吞异常。
6. 构造 same-PK different-value conflict，验证约定的 non-zero exit 和数据不被静默覆盖。
7. 构造真实 batch partial failure：同一 table batch 中先有可写记录、随后触发失败，并验证该 batch 无部分提交。
8. 重跑 execute、second-run idempotency、same-PK conflict、FK orphan、partial rollback、missing source、source immutability 和 12-table consistency。
