# Revid 用户端流程页设计计划

## 目标

在保留现有 Canvas Editor 结构的前提下，把用户端流程页调整为更高级、简约、轻量的视觉方向：

- 画布更像“主舞台”，突出内容和节点层级
- 左侧栏目改成半透明浮窗，弱化工具箱感
- 整体减少原型感，提升完成度与品牌感
- 桌面端和移动端都保持清晰可用
- 视觉气质参考 `libtv` 那种节点工作流感，先做简化版，再逐步精致化

## 设计方向

- 画布：柔和渐变底色 + 细颗粒网格 + 更克制的高光
- 画布：偏暗色系、护眼的背景底色，避免过亮和高饱和刺激色
- 左侧栏目：玻璃拟态浮窗，带轻阴影和模糊背景
- 节点：像工作流一样排布，左输入、中处理、右结果
- 连线：默认保持 1-2px 灰黑色实线，降低视觉噪声和性能消耗
- 连线高亮：节点被选中时，再在实线基础上叠加脉冲、电流传播式的流向效果
- 右侧面板：保持信息密度，但视觉上更轻
- 页面节奏：先保证通俗易懂，再追求精致细节
