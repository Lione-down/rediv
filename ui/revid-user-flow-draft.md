# Revid 用户端完整流程草稿

## 1. 首页 `index.html`

目标：

- 让用户明确知道“从哪里开始”
- 不做营销 landing，直接服务进入工作流
- 提供 4 个最直观的入口

入口与跳转关系：

1. `新建空白画布`
   - 跳转到 `revid-prototype.html?state=empty&entry=blank`
   - 用于完全从零开始
2. `从故事脚本开始`
   - 跳转到 `revid-prototype.html?state=empty&entry=story`
   - 初始化文案偏“先写故事骨架”
3. `角色设定入口`
   - 跳转到 `revid-prototype.html?state=empty&entry=character`
   - 初始化文案偏“先上传参考图 / 建图片节点”
4. `继续最近项目`
   - 跳转到 `revid-prototype.html?entry=story`
   - 直接进入已有节点的工作流页

## 2. 工作流页 `revid-prototype.html`

### 2.1 初始化空画布

当 URL 带 `state=empty` 时：

- 进入空画布引导态
- 中央显示起手式卡片
- 提示用户：
  - 双击左键添加节点
  - 右键上传素材 / 添加节点
  - 拖节点上的 `+` 继续往后连

### 2.2 画布中的常驻交互

这两个能力不是只在初始化态出现，而是整个画布中都可用：

1. 双击左键空白处
   - 打开“添加节点”菜单
   - 可创建文本、图片、模型处理、结果、提示词润色等节点
2. 右键空白处
   - 打开上下文菜单
   - 当前包含：
     - 上传
     - 添加节点
     - 粘贴
     - 预留撤销 / 重做 / 保存到我的资产

### 2.3 画布视觉规则

1. 画布整体偏暗色系，优先使用护眼、低刺激的颜色
2. 节点未选中时，连线保持 1-2px 的灰黑色实线，不做动态流动
3. 节点被选中时，显示该节点相关的所有节点流，并在实线基础上增加脉冲或电流传播式高亮
4. 画布的默认状态以低噪声、低干扰为原则，减少不必要的视觉动效

### 2.4 节点流转

1. 用户创建第一个节点
2. 悬浮节点出现 `+`
3. 按住 `+` 拖出连线
4. 连接目标改为“另一个节点”，不再走松手弹出节点选择菜单
5. 节点选中后展示单选聚焦效果，便于区分当前操作对象

### 2.5 复合节点规则

1. 复合节点拖动生成时，只允许做合成，不允许直接连接已有节点
2. 复合节点中只要包含视频素材，后续可生成结果仅限文本或视频
3. 复合节点的拖拽连接逻辑与普通节点保持一致，最终都以“拖到另一个节点上”为准

## 3. 当前主流程建议

### 流程 A：从故事脚本开始

1. 首页点击 `从故事脚本开始`
2. 进入空画布
3. 通过起手卡片或双击添加 `文本节点`
4. 继续连接 `提示词润色`
5. 再连接 `模型处理`
6. 最后连接 `文生图结果`
7. 如果中间出现复合节点，则按照复合节点的输出约束继续收敛到文本或视频

### 流程 B：从角色设定开始

1. 首页点击 `角色设定入口`
2. 进入空画布
3. 右键选择 `上传` 或直接添加 `图片节点`
4. 补一个 `文本节点` 写角色描述
5. 再连接 `模型处理`
6. 输出 `文生图结果`
7. 节点被选中时，按新的单选态样式显示当前焦点

### 流程 C：继续已有项目

1. 首页点击 `继续最近项目`
2. 直接进入已有节点工作流
3. 在任意空白区域双击添加节点
4. 或在任意空白区域右键上传素材 / 添加节点
5. 直接把节点拖到另一个节点上完成连接，取消松手弹菜单的旧方式

## 4. 这版原型已覆盖的页面关系

- 首页：`ui/index.html`
- 工作流页：`ui/revid-prototype.html`
- 本地预览脚本：`ui/start-preview.ps1`
