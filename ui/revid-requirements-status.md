# Revid 用户端流程页需求与进度记录

## 1. 需求总览

### 1.1 视觉与整体气质

- 参考 `libtv` 的节点工作流观感，但先做一版简化稿
- 整体追求高级、简约、通俗易懂，而不是强原型感
- 尽量把非技术性文案改成中文
- 画布铺满整个页面，类似 Figma 的工作区感
- 左侧工具栏嵌入画布中，做成白色半透明浮窗
- 底部保留半透明输入框

### 1.2 画布与节点交互

- 鼠标靠近节点左右中心约 20px 时显示 `+`
- 节点左右两端都可以作为连接起点或承接点
- 拖动 `+` 时显示节点流向预览线
- 拖到目标节点后直接完成连接，不再依赖松手弹菜单的旧流程
- 已有节点之间可以直接互连，不只是生成新节点
- 节点支持拖拽移动，所有连线实时跟随
- 连线在节点底层，不遮挡节点本体
- 连线用 1-2px 细线，流向感通过动态效果表达，类似“血管 / 流水”
- 节点支持文本、图片、视频、模型处理、结果、润色等类型

### 1.3 多选与流向规则

- 支持框选多个节点
- 多个节点被框选后，可以整组拖动
- 多选节点后，只能从右侧继续拖出下游节点
- 多选生成的新节点应作为汇聚后的下游节点
- 正常链路应符合 `A -> B -> C` 的顺序流向

### 1.4 画布基础操作

- 双击画布空白处可以随时添加节点
- 右键画布空白处可以打开上下文菜单
- 右键菜单中支持上传、添加节点、粘贴等入口
- “双击添加 + 右键菜单”不是初始化专属，而是整个画布全程可用

### 1.5 首页与页面流转

- 需要用户端首页 `index` 页面
- 首页需要更专业的产品感，而不是普通静态入口页
- 右上角收纳个人中心，悬停展示个人信息和跳转入口
- 首页能清楚跳转到流程页面
- 需要把首页、空画布、已有项目、流程页之间的完整交互流程做成草稿

### 1.6 本地预览

- 需要规避 `file://` 页面的访问策略限制
- 本地应可通过 `http://127.0.0.1` 正常预览

### 3.4 本次新增的节点交互需求

- [x] 文本、视频、图片节点已补单选后的效果展示，参考现有产品的选中态与聚焦态表现
- [x] 复合节点拖动生成新节点时，只允许“合成生成”，不允许直接连接已有节点

- [x] 节点未选中时连线保持 1-2px 的灰黑色实线，不再做动态效果，以降低性能消耗
- [x] 节点选中时显示相关节点流，并在实线基础上叠加脉冲 / 电流传播式高亮
