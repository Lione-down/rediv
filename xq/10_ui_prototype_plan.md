# Revid UI 原型初版开发计划

## 目标

基于现有 `ui/design-direction.md` 与 `xq/00_product_requirements.md`，先产出一版可评审的首屏原型，验证 Revid 第一屏的信息层级、布局密度和视觉基调是否符合“安静的创作工作台”方向。

## 范围

- 产出一个桌面端优先的 Canvas Editor 原型页。
- 覆盖顶部状态栏、左侧轻量工具栏、中间主画布、右侧资产与属性面板。
- 展示默认空画布、节点示例、生成任务入口和基础空状态引导。
- 体现移动端收纳策略，但不做完整交互实现。

## 设计约束

- 严格沿用 `ui/design-direction.md` 的视觉 thesis、颜色 tokens、字体栈和布局尺寸。
- 不引入紫蓝渐变、玻璃拟态、营销式 hero 和多余装饰。
- 主视觉必须始终让位给画布区域，侧栏不能抢主视觉。
- 交互重点只做轻量状态切换，避免复杂弹窗和重交互。

## 交付物

- `ui/revid-prototype.html`：单文件静态原型，可直接在浏览器打开。

## 验收标准

- 桌面宽度下，布局清晰呈现 top bar、left toolbar、canvas、right panel 四层结构。
- 画布区域是视觉中心，节点示例和生成入口可快速理解。
- 右侧面板 tab 切换区域、资产列表和属性区域具备明确层级。
- 375px 宽度下不出现严重溢出，侧栏可折叠为底部或纵向堆叠布局。

## 执行步骤

1. 先创建原型计划文档，明确范围与验收。
2. 再实现静态原型页，优先完成结构和视觉基调。
3. 最后回写进度文档，记录已完成项与待对齐项。

计划已建立，等待原型页落地。
